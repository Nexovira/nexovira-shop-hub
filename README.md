# NEXOVIRA Commerce Hub

Act as a senior full-stack engineer. Build the foundation of a production-ready e-commerce website for NEXOVIRA Global Ventures using Next.js 15 (App Router), TypeScript, Tailwind CSS, shadcn/ui, Supabase, and Vercel. Set up the project architecture, routing, reusable components, environment variables, responsive layout, dark mode, SEO, and connect Supabase. Create the database schema and authentication. Produce clean, scalable, production-ready code.

Create a secure admin dashboard using Supabase Authentication. The admin should be able to log in and manage the store. Include dashboard statistics, navigation, profile settings, and role-based access control. Make the interface modern and responsive.

Build a complete product management system. The admin should be able to add, edit, delete, publish, unpublish, and duplicate products. Products should support multiple images, categories, price, discount, SKU, stock quantity, descriptions, specifications, digital downloads, and inventory tracking. Store images in Supabase Storage

Build the customer-facing e-commerce storefront. Include a beautiful homepage, hero banner, featured products, categories, best sellers, new arrivals, search, filters, sorting, product cards, product details page, wishlist, and responsive design.

Build a complete shopping cart and checkout system. Customers should be able to add items to the cart, update quantities, remove products, apply coupons, calculate shipping, and complete checkout. Integrate Paystack for secure payments. Save completed orders in Supabase.

Build customer authentication using Supabase. Create registration, login, forgot password, profile editing, address management, order history, wishlist, digital downloads, and order tracking.

Build an order management system for administrators. Display all orders, payment status, shipping status, customer information, invoices, refunds, cancellations, analytics, and email notifications.

Add product reviews, ratings, blog, newsletter, FAQs, WhatsApp chat, live search, recently viewed products, recommended products, flash sale countdown, SEO optimization, sitemap, robots.txt, structured data, Google Analytics integration, and responsive animations.

Review the entire application. Fix all bugs, optimize performance, improve accessibility, optimize SEO, secure API routes, optimize database queries, compress images, and prepare the application for production deployment.

Prepare the complete project for deployment on Vercel. Verify all Supabase integrations, environment variables, Paystack integration, image uploads, authentication, and production settings. Ensure the website is fully functional on my custom domain nexovira.name.ng.
